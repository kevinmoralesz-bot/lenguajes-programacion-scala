## Contenido

- `Semana02`: tres programas resueltos mediante funciones e iteradores.
- `Semana03`: tres programas resueltos con funciones definidas y operaciones sobre colecciones.
- `Semana04`: tres soluciones diferentes que reciben funciones como parámetros y emplean funciones de orden superior.

Cada carpeta contiene:

- `Main.scala`: código fuente comentado.
- `evidencia.png`: captura con la ejecución y el resultado obtenido.
- `salida.txt`: registro textual de la ejecución validada.

La raíz también contiene `RESUMEN_EVIDENCIAS.png`, con una vista conjunta de
los resultados de los nueve programas.

## Ejecución

Desde la carpeta de cualquier programa:

```bash
scalac Main.scala
scala Main
```

Los programas interactivos de la Semana 02 solicitan los valores indicados por teclado.
